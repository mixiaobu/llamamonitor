Settings

Server

llama-server 基础地址。监控只 GET metrics 端点，绝不触碰服务器本身。

任意基础地址（http/https），如 http://192.168.1.100:9091；不要包含 metrics 路径。

Collector

Metrics 采集参数。

Changes take effect after restarting LlamaMonitor.

GPU

Windows NVIDIA 只读监控（数据来自系统 NVIDIA 驱动自带的 nvidia-smi；不控制 GPU、不改功耗/频率）。

Database Health

Status加载中… Journal Mode--

检查 = PRAGMA quick_check（只读，不修复、不删库）。通过：状态恢复 healthy、写入继续；失败：进入 protective mode（只读，停止修改类写入，采集与展示继续）。启动时已自动执行一次。

Automatic Backup

手动备份永不参与轮转。每个备份创建后立即 quick_check 验证（见下方列表的 Verified 列）。更改需重启 LlamaMonitor 生效。Backup restore is not yet supported from the running application.

Export & Backup

备份保存在 backups 目录（见上方 Backup Count）。手动备份立即创建并验证。

Clear（警告操作）

只删除 live_samples（实时采样）；每日累计与计数器 baseline 不受影响。

Danger Zone（危险操作）

删除全部历史统计并从现在开始重新累计。不影响 llama.cpp（Counter baseline 保留，旧 Token 不会重新计入）。

Application

系统托盘、单实例、Windows 开机自启与退出。关闭 Dashboard 窗口只会隐藏到托盘，监控继续。

Updates

版本检查与更新（GitHub Releases + Ed25519 签名 manifest + SHA-256 校验）。 更新检查默认关闭；启用后 LlamaMonitor 会定期向受信任的 GitHub 仓库请求最新版本信息 （只发送版本相关请求，不发送 token / GPU / 模型名 / 数据库数据 / 设备 ID）。 更新永远需要确认后才安装，绝不静默自动安装。
