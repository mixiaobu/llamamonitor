    危险操作

    以下操作不可撤销，确认后立即生效。

    清空短期历史
    删除全部实时采样历史（llama.cpp 指标 + GPU 样本）。每日统计汇总与计数器基线会保留。
    重置统计数据
    删除 Token 用量历史（每日聚合）、GPU 统计、MTP 统计、实时采样与采集缺口记录。计数器基线会保留，计数从当前会话继续。
